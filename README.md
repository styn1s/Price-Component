# 💰 Price Component
A clean, responsive pricing card component built with HTML and CSS. This project presents a subscription plan for a community or service, featuring a clear call-to-action and a list of benefits.

![Screenshot of the page](/images/screenshot.png)

## ✨ Features
- Responsive Layout: Adapts seamlessly to different screen sizes (desktop, tablet, mobile).

- Clear Pricing Structure: Highlights the subscription cost, duration, and value proposition.

- Benefit List: Showcases key features to inform user decisions.

- Call-to-Action Button: A prominent "Sign Up" button to encourage conversions.

- Modern Design: Uses a clean, professional color scheme and typography.

## 🚀 Live Demo
You can view the live page here: https://styn1s.github.io/Price-Component/

## 🛠️ Technologies Used
- HTML5: For the page structure and semantic content.

- CSS3: For styling, layout and responsive design.
